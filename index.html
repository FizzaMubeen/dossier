Spreadsheet (.xlsx or .csv)

Columns recognised (any order, case-insensitive): Type, Status, Company, Position, Location, Source, Applied Date, Deadline, Link, JD, Notes. Unrecognised columns are ignored. Unknown Status/Type values fall back to "Saved" / blank.

Documents (.zip)

Name each file starting with the entry's Case ID (shown on its card, e.g. JT-004), followed by an underscore or dash and a label — e.g. JT-004_CV.pdf, JT-004_Cover-Letter.docx. Matching files are attached automatically. Files that don't match an existing entry are listed so you can rename and retry.

🔒 Security

Encrypts all entries and attached files at rest (AES-256) so they can't be read without this passphrase — even by someone with direct access to the browser's storage files. There is no password reset. If you forget it, the only way back is a backup exported before you forget it.
